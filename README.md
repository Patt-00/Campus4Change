# Campus4Change — Splash Screen Prototype

This branch contains only the standalone JavaScript React + Vite splash/introduction prototype and its Laboratory Activity 4.1 documentation. The full native Android application is not included in this branch's current files; it remains on `main` and `javascript-version`.

- [Prototype source and screen guide](splash-screen/README.md)
- [Documentation: Word, PDF, Markdown and screenshots](docs/lab4.1/README.md)

## Run

```sh
cd splash-screen
npm ci
npm run dev
```

## Verify

```sh
cd splash-screen
npm run lint
npm run build
```

The prototype includes the splash, three introductions, and sample Login/Sign Up destinations. It does not authenticate, save accounts, or build an APK.

The documentation is a group-review draft. Add the original Figma introduction screenshots and review the disclosed AI assistance before final submission.
